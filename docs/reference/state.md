# awt state

Leave the handoff: where things stand and what comes next.

```
awt state --now NOW --next NEXT [--scope SCOPE]
```

## Flags

| Flag | Meaning |
|---|---|
| `--now NOW` | where things stand |
| `--next NEXT` | what the next session should do |
| `--scope SCOPE` | name of a sub-unit of work |

Global flags `--dir`, `--by` and `--model` work with every verb. Exit codes: 0 ok, 1 refused, 2 usage, 3 permissions, 4 no task or id.
