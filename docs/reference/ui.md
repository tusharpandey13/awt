# awt ui

Browse store.db in a read-only web page (needs datasette).

```
awt ui [--port PORT] [--print-metadata]
```

## Flags

| Flag | Meaning |
|---|---|
| `--port PORT` | port on 127.0.0.1 (default 8777) |
| `--print-metadata` | print the page metadata and exit |

Global flags `--dir`, `--by` and `--model` work with every verb. Exit codes: 0 ok, 1 refused, 2 usage, 3 permissions, 4 no task or id.
