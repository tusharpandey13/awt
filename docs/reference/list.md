# awt list

List what is known about the task, one section or all.

```
awt list [--all] [--json] [--since SINCE] [--down] SECTION
```

## Arguments

| Argument | Meaning |
|---|---|
| `SECTION` | one section: refs, context, docs, outbox, misc, decisions, questions, effects, notes, state, nodes or tree |

## Flags

| Flag | Meaning |
|---|---|
| `--all` | include superseded, answered and finished items |
| `--json` | machine-readable output |
| `--since SINCE` | only records after this ISO 8601 time |
| `--down` | include the nodes below this one |

Global flags `--dir`, `--by` and `--model` work with every verb. Exit codes: 0 ok, 1 refused, 2 usage, 3 permissions, 4 no task or id.
