# awt supersede

Move a doc replaced by a better one to docs/_superseded/.

```
awt supersede [--why WHY] OLD NEW
```

## Arguments

| Argument | Meaning |
|---|---|
| `OLD` | the old doc under docs/ |
| `NEW` | the new doc under docs/ |

## Flags

| Flag | Meaning |
|---|---|
| `--why WHY` | the reason |

Global flags `--dir`, `--by` and `--model` work with every verb. Exit codes: 0 ok, 1 refused, 2 usage, 3 permissions, 4 no task or id.
