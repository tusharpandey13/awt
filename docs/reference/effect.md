# awt effect

Declare an outbound send so it is made once: plan, begin, mark, show.

```
awt effect
```

## Steps

- [`awt effect plan`](effect-plan.md): Declare a send before it happens.
- [`awt effect begin`](effect-begin.md): Claim a planned send; send it yourself after this.
- [`awt effect mark`](effect-mark.md): Record how a send ended.
- [`awt effect show`](effect-show.md): Print one effect: state, attempts, how, body.

Global flags `--dir`, `--by` and `--model` work with every verb. Exit codes: 0 ok, 1 refused, 2 usage, 3 permissions, 4 no task or id.
