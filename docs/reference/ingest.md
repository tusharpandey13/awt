# awt ingest

Copy agent transcripts into the store and update store.db; with --event, record one tool call.

```
awt ingest [--source SOURCE] [--hook] [--rebuild] [--stdin] [--event]
```

## Flags

| Flag | Meaning |
|---|---|
| `--source SOURCE` | claude, pi, opencode, paseo, ccusage (usage totals) or all; default claude |
| `--hook` | silent, exit 0 on any error (for a hook) |
| `--rebuild` | delete store.db and build it again from the stored logs |
| `--stdin` | read plugin events from stdin (with --source paseo) |
| `--event` | read one tool-call event on stdin and record a detected effect |

Global flags `--dir`, `--by` and `--model` work with every verb. Exit codes: 0 ok, 1 refused, 2 usage, 3 permissions, 4 no task or id.
