# awt answer

Answer a question.

```
awt answer ID TEXT
```

## Arguments

| Argument | Meaning |
|---|---|
| `ID` | question id, such as q-1a2b3c4d |
| `TEXT` | the answer |

Global flags `--dir`, `--by` and `--model` work with every verb. Exit codes: 0 ok, 1 refused, 2 usage, 3 permissions, 4 no task or id.
