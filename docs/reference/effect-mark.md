# awt effect mark

Record how a send ended.

```
awt effect mark [--ref REF] [--why WHY] ID TO
```

## Arguments

| Argument | Meaning |
|---|---|
| `ID` | effect id |
| `TO` | sent, not-sent (needs --why), unknown (needs --why) or dropped |

## Flags

| Flag | Meaning |
|---|---|
| `--ref REF` | link to the sent item |
| `--why WHY` | the reason |

Global flags `--dir`, `--by` and `--model` work with every verb. Exit codes: 0 ok, 1 refused, 2 usage, 3 permissions, 4 no task or id.
