# awt capture

Save pasted text that cannot be linked into context/.

```
awt capture --from FROM --title TITLE [--ref REF] FILE
```

## Arguments

| Argument | Meaning |
|---|---|
| `FILE` | file to read; stdin when absent or - |

## Flags

| Flag | Meaning |
|---|---|
| `--from FROM` | where it came from, such as slack (required) |
| `--title TITLE` | short title (required) |
| `--ref REF` | URL of the original |

Global flags `--dir`, `--by` and `--model` work with every verb. Exit codes: 0 ok, 1 refused, 2 usage, 3 permissions, 4 no task or id.
