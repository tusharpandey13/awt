# awt effect plan

Declare a send before it happens.

```
awt effect plan --target TARGET [--body BODY] [--how HOW] [--after AFTER] [--again] [--why WHY]
```

## Flags

| Flag | Meaning |
|---|---|
| `--target TARGET` | where it goes, such as slack:#eng (required) |
| `--body BODY` | file holding the text to send |
| `--how HOW` | the command you will run (text only; awt never runs it) |
| `--after AFTER` | id of an effect that must be sent first (repeatable) |
| `--again` | plan a send of something already sent |
| `--why WHY` | the reason |

Global flags `--dir`, `--by` and `--model` work with every verb. Exit codes: 0 ok, 1 refused, 2 usage, 3 permissions, 4 no task or id.
