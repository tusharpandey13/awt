# awt reference

One page per verb. Start with [concepts](../concepts.md); `awt --help` prints the same list.

| Verb | What it does |
|---|---|
| [`init`](init.md) | Create a task directory, or a node of the tree with --kind. |
| [`resume`](resume.md) | Print the brief: goal, state, open questions and effects, what changed since the last handoff. |
| [`list`](list.md) | List what is known about the task, one section or all. |
| [`find`](find.md) | Search records and files; --like ranks related records from the whole tree. |
| [`state`](state.md) | Leave the handoff: where things stand and what comes next. |
| [`note`](note.md) | Record a small fact for later. |
| [`decide`](decide.md) | Record a choice and its reason. |
| [`ask`](ask.md) | Record a question for a person. |
| [`answer`](answer.md) | Answer a question. |
| [`ref`](ref.md) | Record a link instead of copying its content. |
| [`capture`](capture.md) | Save pasted text that cannot be linked into context/. |
| [`supersede`](supersede.md) | Move a doc replaced by a better one to docs/_superseded/. |
| [`status`](status.md) | Set the task status; done is refused while questions or effects are open. |
| [`doctor`](doctor.md) | Check the task: layout, git, disk, settings, store. Prints ok, warn or fail per check. |
| [`ingest`](ingest.md) | Copy agent transcripts into the store and update store.db; with --event, record one tool call. |
| [`ui`](ui.md) | Browse store.db in a read-only web page (needs datasette). |
| [`help`](help.md) | Print this summary; help agents prints the agent reference. |
| [`effect`](effect.md) | Declare an outbound send so it is made once: plan, begin, mark, show. |
| [`effect plan`](effect-plan.md) | Declare a send before it happens. |
| [`effect begin`](effect-begin.md) | Claim a planned send; send it yourself after this. |
| [`effect show`](effect-show.md) | Print one effect: state, attempts, how, body. |
| [`effect mark`](effect-mark.md) | Record how a send ended. |

Global flags: `--dir PATH` use the node at PATH instead of the current directory; `--by NAME` who is writing (default $AWT_BY, else agent); `--model ID` model that produced this write (default $AWT_MODEL, else unknown:unset); `--version` print the version.
