# awt status

Set the task status; done is refused while questions or effects are open.

```
awt status active|paused|done
```

## Arguments

| Argument | Meaning |
|---|---|
| `VALUE` | active, paused or done |

Global flags `--dir`, `--by` and `--model` work with every verb. Exit codes: 0 ok, 1 refused, 2 usage, 3 permissions, 4 no task or id.
