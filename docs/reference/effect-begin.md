# awt effect begin

Claim a planned send; send it yourself after this.

```
awt effect begin ID
```

## Arguments

| Argument | Meaning |
|---|---|
| `ID` | effect id, such as e-3c91d0aa |

Global flags `--dir`, `--by` and `--model` work with every verb. Exit codes: 0 ok, 1 refused, 2 usage, 3 permissions, 4 no task or id.
